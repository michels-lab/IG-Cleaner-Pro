## v120.38 — Android Focus data parity, Double Check and cross-device batch history

- **Android Focus displays the same relationship facts available on Desktop:** exact/relative date the user followed, when the other account followed, which relationship started first and the time difference; confirmed/missing relationship context, most recent review/decision, saved opening/review history, and available source/quality details. Missing timestamps stay labeled **Sin fecha**.
- **Native Double Check 30 on Android** revisits accounts not appearing among current Followers and rotates distinct usernames over a shared Desktop–Android cycle, with explicit end-of-cycle restart; protected, snoozed and concurrently active profiles are excluded. Opening a profile never implies that a review was confirmed.
- **Per-section last-batch history** visible in Android for Review, Mutuals, Followers, Pending and Double Check; shows date, status, count and source device, including historical Desktop audit-only activity.

The native Sync action now refreshes an open Focus batch as well as idle lists. Partial Followers HTML remains **NO VERIFICABLE**; uncertain absence is not treated as proof of no follow-back.
