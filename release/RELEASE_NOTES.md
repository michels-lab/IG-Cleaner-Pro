## v120.41 — Desktop profile selector and safe IG Cleaner account switching (Desktop + Android)

- **Desktop multi-Instagram identity restored:** selected @username is displayed in full on a dedicated readable card, and the profile picker uses its own full-width row instead of being squeezed to “Dat”. Independent **Actualizar perfiles** pulls the authenticated account registry and per-profile summaries from the cloud. An explicit signed-out/auth/network status explains when only local “Datos anteriores” is available.
- **Switch IG Cleaner app accounts:** Desktop **Cambiar usuario** and native Android **Switch account** live beside the existing sign-out action. Confirmed switching ends the old login and offers a fresh email/password without deleting the user's Instagram workspaces, reviews, Focus history, local backups or owner-isolated cloud records. Switching the IG Cleaner *login* differs from choosing an Instagram profile *inside* that login.
- **Auth session hardening:** Android validates that an embedded WebView session belongs to the same owner as the native app and prevents stale login/anonymous bootstrap from overwriting the current native identity. A failed password sign-in no longer changes the active owner prematurely. Desktop avoids account switching during active synchronization.
- **No destructive migration or new auth provider:** existing legacy Instagram lists and pre-v120.39 review history remain intact; original ZIP exports remain local and owner-scoped RLS protections remain in force.
- **Synchronized stable binaries:** release **v120.41** includes the standalone/offline Desktop HTML (recommended), optional Desktop ZIP and production-signed Android APK **com.michelslab.igcleaner**, versionCode **12041**, versionName **120.41**, original long-lived signing certificate. Version and checksum verification run in the governed publisher; these are not beta artifacts.
- **Automated checks:** real Desktop Chromium compact/wide UI screenshots and Android installed-emulator compact/wide Home/About evidence, Android build, standalone browser/contract checks and **99 PostgreSQL/RLS assertions** must pass on the exact candidate. User's visual review occurs after publication.

**Device follow-up:** Real Samsung update from v120.40, genuine multi-Instagram ZIP data/legacy recovery, and two IG Cleaner account sessions / Desktop↔Android sync remain post-release acceptance under [#24](https://github.com/michels-lab/IG-Cleaner-Pro/issues/24). Automated emulation does not prove tests on a physical phone or sign-in with the user's actual credentials.
