## v120.38 — Android Focus information parity, Double Check and cross-device history

- **Android Focus now displays the useful Desktop information**, including exact and relative dates for when you followed an account and when it followed you; who followed first and the time difference; relationship status/evidence; last confirmed review, recorded decision, available profile opening/review history, original export provenance, and historical context. Unknown dates show *Sin fecha* instead of invented values.
- **Double Check 30 runs natively on Android**, prioritizing unconfirmed no-followback relationships and rotating batches without repeating usernames during a cycle. The Desktop and Android cycle state sync through authenticated Supabase `workspace_state.focus_double_check_cycle`, independently from canonical review history. Restart is explicit after exhausting eligible profiles.
- **Last batch/activity visible by section** in native Android Focus: Review, Mutuals, Followers, Pending, and Double Check. Includes date, count when present, state, source device and completion time; recognizes historical Desktop audit-only batches and active-batch refresh.
- **Safer review semantics:** opening a profile and confirming a review remain distinct; Double Check review decisions are explicitly confirmed. A partial Followers HTML export cannot establish that an absent follower *doesn't follow back*; this uncertainty is synced and enforced on Android.
- **Performance:** relationship indexes are built once per native Focus batch instead of for every profile; no destructive IndexedDB/localStorage schema migration and no new cloud tables.
- **Validation:** Android real installed-APK emulator at compact and wide viewports (Home/About screenshot checks plus five instrumentation tests per viewport), actual Desktop Chromium Home/About/standalone offline UI tests, Android package build/signing verification, and 41 cross-account/data-boundary Supabase RLS tests are mandatory on this release commit. Final publisher verifies the original persistent **FINAL-9999** production signing identity, package ID `com.michelslab.igcleaner`, `versionCode 12038`, `versionName 120.38`, primary standalone Desktop HTML, Desktop ZIP, and SHA256SUMS. Same v120.38 on both platforms.
- **Acceptance separate:** genuine Instagram ZIP, the user's physical Samsung install/update, and real authenticated Desktop↔Android session roundtrip require the user's post-release verification; these were not claimed by automated CI.

**Stable release, not prerelease.** Automated CI and real runtime gates are compulsory. Human visual review is **after** publication, not a pre-publication blocker.
