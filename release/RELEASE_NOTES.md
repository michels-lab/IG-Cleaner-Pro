## v120.42 — Automatic Instagram Profile Counts (Windows collector + Desktop/Android sync version)

- **Windows robot (new ZIP):** Download `IG-Cleaner-Pro-Automatic-Robot-Windows-v120.42.zip`, extract the complete folder and double-click `Start-Insta-Cleaner-Robot.cmd`. Requires installed Google Chrome; does not require Python or a Meta API key. Insta Cleaner starts the visible Instagram browser. After you sign in personally, it attempts to detect your Instagram account, discover the list of profiles you follow and collect each profile's visible Followers and Following counts automatically.
- **Hands-off normal flow:** no manual Following CSV, no Start button and no pacing setup in the visible interface. The collector records progress and uses persisted internal visit windows, post-profile gaps and optional extended rests. It stops for Instagram verification, account mismatch and platform access restrictions instead of evading them. It can report incomplete Following discovery; missing counts never become invented zeros.
- **Results and account isolation:** Insights → Profile Counts displays the records as they arrive in the Desktop workspace. The robot and results remain scoped to the selected IG Cleaner login and Instagram account. Existing manual CSV import/export survives as fallback, not as the expected workflow.
- **Android:** Production-signed `IG-Cleaner-Pro-Android-v120.42.apk` is included with package `com.michelslab.igcleaner`, versionCode `12042` and the same long-lived signing certificate as v120.41. The existing embedded Insights workspace is retained. **Android does not run the Chrome/Playwright automation locally**; its new counts do not yet synchronize automatically from Windows, so do not expect autonomous Android crawling.
- **Desktop:** Standalone `IG-Cleaner-Pro-Desktop-v120.42.html` and full `IG-Cleaner-Pro-Desktop-v120.42.zip` remain available for regular review, account switching and local Instagram export analysis. For automatic Instagram collection use the distinct Windows robot ZIP.
- **Validation:** Offline Python/Node functionality and account-boundary tests, full Chromium `file://` ↔ localhost fixture interaction, real Desktop Home/About screenshot tests, installed Android emulator visual tests, production certificate assertions and Windows frozen executable healthcheck form the automated release gates.

**Critical limitation for testing:** Automated Instagram profile enumeration against the owner's actual logged-in session has **not** been proven yet; live DOM/layout changes, private account restrictions or automation challenges may interrupt or incompletely populate the list. The Windows robot is released **for user testing**, not guaranteed complete collection, and does not defeat platform restrictions. PC must remain powered on. Do not share Chrome cookies, the local controller URL or account backup files. Existing review/workspace data are preserved; avoid moving the HTML file used for previously stored browser state without taking backups.

**Device follow-up:** Actual Samsung signed-APK upgrade and real Instagram login/counters with the Windows robot are owner acceptance tests, not claims of CI proof.
