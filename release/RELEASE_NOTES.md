## v120.39 — Multiple Instagram profiles per IG Cleaner login (Desktop + Android)

- **One IG Cleaner login, multiple distinct Instagram workspaces.** Create, rename/label and switch between Instagram identities in Desktop and native Android. A stable opaque `account_key` rather than the handle is the workspace identifier, so username changes cannot merge data.
- **Strict per-Instagram isolation:** Following, Followers, Pending, history, reviewed/protected/snoozed decisions, Focus batches, Recheck/Double Check cycle, snapshot data and Supabase sync are scoped to each Instagram profile. Duplicate usernames across two Instagram identities retain separate states.
- **Desktop + Android profile selection:** Desktop workspace selector; native Android Profile manager and tappable always-visible header account label. Switches reload the relevant state; signing into another IG Cleaner login does not reveal previous login's nonlegacy local workspace registry.
- **Data safety:** pre-v120.39 local/browser/Supabase workflow data stays in the original `legacy` profile, with its existing storage keys and cloud tables unchanged. The additive, RLS-protected seven-table per-profile Supabase schema has already been deployed. Original Instagram ZIP/HTML/JSON exports stay on the device; cloud sync handles normalized data.
- **Regression:** removed literal visible `\\n\\n` text above the Desktop sidebar. Preserve the approved logo and About, permanent Android About/Sync access, local privacy controls, full native Focus fields, Double Check 30 and last-batch summaries from v120.38.
- **Coordinated stable release:** Desktop standalone HTML (primary) + optional ZIP and Android production signed APK use v120.39, with Android versionCode 12039, original app ID `com.michelslab.igcleaner` and identical production signing certificate (FINAL-9999). Never ship a debug/beta Android APK as stable.
- **Release gates:** run current-commit Android build and installed-emulator Home/About/Focus regression, real Desktop Chromium visual/selector tests, Supabase 60-assertion RLS suite, standalone/offline artifact tests and production certificate verification before publishing. No required human pre-release review.

**Post-release real-device acceptance remains open:** actual Samsung update over previous version, genuine exports for two Instagram accounts, live authenticated Desktop↔Android switching/roundtrip and raw-data non-upload confirmation. Do not claim that CI alone proves physical device behavior. GitHub stable release is not a Google Play listing.
