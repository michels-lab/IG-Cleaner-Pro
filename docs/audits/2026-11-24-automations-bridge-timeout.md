# Automations Activity & History: independent live status and bounded local reads

2026-11-24. Source after #410. Before this change a bridge fetch or JSON body that never finished kept `loading=true`, disabled Refresh, prevented account-switch history recovery and postponed live batch status. A stopped historical batch also masked a second unavailable supervisor. The fix bounds the full read to 8 seconds with AbortController and a rejecting deadline; starts status in parallel with journal reads; preserves task-specific partial lower bounds, unknown totals and previous account epoch fencing. An unavailable supervisor cannot be interpreted as stopped solely from a historical stopped batch. No history mutations, real account requests, release or relationship clicks.

Regression: `tests/automation-activity-aba-browser.test.cjs` uses actual production script in Chromium and a delayed body/bridge fixture; asserts batch state visible before journal resolution, partial ≥1, bounded abort, both histories unavailable, unknown supervisor status, enabled retry and recovery. Existing ABA/owner switch regression preserved. CI pending until exact head evidence. #377 and #360 physical acceptance remain open. P0 7/12 (58%).
