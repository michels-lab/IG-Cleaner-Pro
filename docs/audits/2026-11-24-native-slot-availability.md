# Independent Windows startup slot availability

2026-11-24. Previously the native chooser always offered both slots, including an already-running window, then failed later at the authoritative mutex. Now it reads existing named mutexes without creating them, offers only available slots, explains occupied/unavailable slots, and offers Cancel even if both are occupied. Production and Developer mutex namespaces are separate. The actual launch still atomically reserves the selected mutex, so a competing startup cannot create duplicate windows. No account login, Chrome profile migration, browser data write, or Instagram call is made by the chooser. Negative regressions cover both occupied, each occupied, cancellation and stale/unavailable selection; native Windows runtime probe tests the real mutex lifetime.
