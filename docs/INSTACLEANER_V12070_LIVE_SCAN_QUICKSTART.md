# Windows quickstart — InstaCleaner v120.70 live Followers & Following

1. Download [official Windows Setup v120.70](https://github.com/michels-lab/IG-Cleaner-Pro/releases/download/v120.70/IG-Cleaner-Pro-Windows-Setup-v120.70.exe) and install for your existing Windows user. Normal and Developer installers are distinct. Keep the same existing app login and robot Chrome workspace; export a local backup before migrating data.
2. Open **InstaCleaner Pro → Automations → Verify live Followers and Following**. Select the exact Instagram account and explicitly agree to a **read-only on-demand scan**. This step needs neither ZIP import nor navigation to each person's profile.
3. In the persistent robot Chrome window, log in manually as that account if needed; handle any Instagram security challenge directly in the browser. Do not send passwords, OTPs, recovery codes, cookies or tokens to ChatGPT.
4. Let the two account-list JSON collections load. The app requests at most 200 members per response, but Instagram may return fewer. Progress shows loaded unique members/pages and safety rests. **Only complete Followers AND Following lists** can produce Followers, Following, Not following me back and Fans counts, with a dated snapshot. No automatic Unfollow, Cancel Pending or review-state mutation.
5. Pacing is intentionally conservative: 2.5 seconds between page GETs; rests of 12 seconds every five pages and 90 seconds every 25. Stop scan interrupts a rest without saving a partial result. On 429/403/503/`feedback_required`, the app stops and holds a persistent **at least 30-minute shared Chrome cooldown**, honors longer `Retry-After`, and blocks switching to a different workspace to evade that timer. A successful run is separated from the next by 15 minutes.
6. If the scan says `blocked`, `incomplete`, `challenge`, `wrong account` or max-pages: do **not** interpret missing users as unfollowers, and do not repeatedly click Verify. The undocumented Instagram endpoint may simply be unavailable. Existing complete saved snapshots remain historical, not proof of current followers. These delays lower request pressure but **cannot guarantee Instagram will not restrict access**.
7. For the first real-world acceptance, report only whether **both lists completed**, the four totals/date or the exact displayed error. Never share authentication/session details. The first owner test of v120.70 is not proven by GitHub QA; this feature runs in installed Windows, not Android or an ordinary standalone HTML browser tab.
