# IG Cleaner v120.69 — verificar seguidores y seguidos en Windows

1. Download the official **[Windows Setup v120.69](https://github.com/michels-lab/IG-Cleaner-Pro/releases/tag/v120.69)** and run it. You can install over the previous version; keep the same Windows user account and browser workspace. Before any high-stakes migration, export your local review/history backup.
2. Launch **Insta Cleaner Pro** from the Windows Start menu, sign in to your existing app login, and select the **exact Instagram account/workspace** you want to check.
3. Go to **Automations** and locate **Verify live Followers and Following**. Click it and explicitly confirm the read-only request. This is **separate from ZIP import**, Profile Counts and the Unfollow/Cancel robots.
4. The app opens its own persistent **robot Chrome session**. If it displays the Instagram login, sign in manually to the *same* Instagram @handle you selected in the app. Do not enter your password into a chat; do not use a different signed-in Chrome profile. If Instagram requests a security challenge, complete the challenge manually in Chrome; the scan pauses rather than attempting to bypass it.
5. Let both Followers and Following complete. View **Not following me back**, **Followers**, **Following**, or **Followers I do not follow (Fans)**, with counts and last verified timestamp. The app saves a per-account dated complete snapshot. It does **not** automatically unfollow anyone.
6. If **Blocked**, **Paused**, owner mismatch or an incomplete scan appears, do not assume missing accounts do not follow you. Close/stop any other running Instagram robots, verify the exact session, and retry manually only when Instagram permits. Instagram may reject its undocumented list API or rate-limit requests. The initial safety cap is about **25,000 entries per list**, which fails closed instead of producing fabricated negatives.

**Platform limitations:** This reader is in the **Windows native installed app** (not the standalone HTML in a normal browser and not Android's native app). Real account Instagram list retrieval has not been personally validated by CI or ChatGPT; the owner must verify on their installed PC. Report the UI's specific status/error for diagnosis; do not share cookies, tokens or passwords.
