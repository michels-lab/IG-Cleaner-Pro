Acerca del proyecto

Acerca de Instagram Cleaner Pro

Análisis local, seguro y trazable de exports de Instagram.

Instagram Cleaner Pro compara followers y following, organiza revisiones y conserva tus decisiones sin iniciar sesión en Instagram. Si activas sincronización, las listas normalizadas y el estado de revisión se guardan de forma privada en tu cuenta de Supabase para mantener Desktop y Android al día.

El export original permanece local. Tú decides cada acción y qué estado sincronizas entre tus dispositivos.

Instagram Cleaner Pro — Privacidad

LOCAL-FIRST El export original de Instagram (ZIP/JSON/HTML) se procesa localmente y no se sube como respaldo en la nube. SI ACTIVAS SYNC Se pueden guardar de forma privada en tu cuenta datos normalizados necesarios para Desktop ↔ Android: listas de usernames/relaciones, estado reviewed/protected/snoozed, Focus batches, eventos de auditoría y datos de dispositivo. ALMACENAMIENTO LOCAL La app usa localStorage y IndexedDB para conservar estado, revisiones y snapshots. Ese estado permanece hasta que lo eliminas/restableces o una migración documentada lo transforma. BACKUP / CAMBIOS Antes de un reset o migración destructiva, exporta un respaldo desde Vault. Cambiar de origen/ruta/perfil del navegador puede abrir un contexto de almacenamiento distinto. GESTIÓN DE DATOS SINCRONIZADOS Puedes exportar a JSON todos los datos que esta cuenta tiene actualmente en la nube o borrar todas sus filas sincronizadas. El borrado de nube no elimina el ZIP/JSON/HTML original ni respaldos locales independientes. Después de borrar la nube, la app cierra la sesión para impedir que el auto-sync vuelva a cargar inmediatamente el estado local.
Inicia sesión en Cuenta para exportar o borrar datos sincronizados.
